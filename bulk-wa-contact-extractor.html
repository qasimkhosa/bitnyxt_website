How to export WhatsApp contacts to Excel

  1. Install the extension from the Chrome Web Store.
  2. Open WhatsApp Web and sign in. Refresh the page if it was open during installation.
  3. Click the extension toolbar icon to open the sidebar.
  4. Choose Groups, Chat List or Business Labels and select the sources you need.
  5. Preview the available rows and warnings, then download the XLSX workbook.

Free to install. Full export visibility is enabled in the current release without a license key. Available fields still depend on WhatsApp Web.

Why are phone numbers missing?

Only information made available by WhatsApp Web can be exported. Hidden or unavailable numbers are not guaranteed to be recoverable. Full export access cannot restore information that WhatsApp Web does not provide.

Can I use the workbook with my CRM?

Check your CRM's accepted formats and field mapping. If it requires CSV, open the relevant worksheet in your spreadsheet application and save that sheet as CSV.

Need help with the sidebar?

Refresh WhatsApp Web, wait for chats to load, and click the extension icon again. Contact support with your extension version and error text if the problem continues. Do not include private contact lists in public support messages.

Independent BitNyxt extension, not affiliated with WhatsApp or Meta. Export only contacts you have permission to process.

Features

What the extension exports

The extension runs only on WhatsApp Web and helps the user export data they explicitly choose to capture from the current workspace.

CT

Contacts

Export saved or unsaved contact details visible in WhatsApp Web into structured rows for spreadsheet review or CRM import.

  • Phone numbers when available
  • Contact and group names
  • Spreadsheet-ready output
GM

Group members

Extract group member lists, including admin state where visible inside the current group context.

  • Group member export
  • Admin state when available
  • Excel workbook support
LB

Chat list and labels

Capture chat list rows, labels, and recent summaries to support follow-up organization and operations workflows.

  • Labels when available
  • Recent message summaries
  • Sidebar-based workflow
Permissions

Why the extension needs its permissions

tabs

Used to find, focus, open, and message the correct WhatsApp Web tab after the user clicks the extension icon.

storage

Used to persist sidebar state, license state, and service-worker recovery state between sessions.

https://web.whatsapp.com/*

Required so the content script can run on WhatsApp Web and extract the data the user has chosen to export.

https://api.polar.sh/*

Reserved for compatibility with earlier license-related product features. The current release does not require a license key for full export visibility.

Privacy summary

Data use is limited to the export workflow

The extension accesses WhatsApp Web content necessary for the user-requested export flow, such as contact or group names, phone numbers when available, labels, recent summaries, member state, business status when available, and notes stored in WhatsApp Web local IndexedDB.

  • Stores local UI and compatibility state
  • Generates requested export files locally on the device
  • Export only contacts you have permission to process
