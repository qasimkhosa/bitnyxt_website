WhatsApp Contacts to Excel/Group export guide
BitNyxt guide · 19 September 2026

How to export WhatsApp group contacts to Excel

Create an Excel workbook from the group contacts available in your WhatsApp Web session. Choose the group, check the preview, then download the file to your computer.

Add to ChromeRead the steps

Before you begin

Use Chrome on your computer and sign in to WhatsApp Web. Start with one group whose contact information you have permission to process. Keep WhatsApp Web open while preparing the export.

The BitNyxt extension generates an Excel workbook (.xlsx). Full export access is currently available without a license key. It can only export information WhatsApp Web makes available; a missing phone number cannot be recovered simply by exporting again.

Select, preview and export

  1. Install and open the sidebar. Install WhatsApp Contacts to Excel — BitNyxt from the Chrome Web Store. Refresh WhatsApp Web if it was already open, then click the extension icon in Chrome's Extensions menu.
  2. Load the group list. Wait for WhatsApp to finish loading. If the list looks incomplete, use Refresh Context in the sidebar.
  3. Choose Groups. Select the group you need. Keep Export all groups off when you only want selected groups.
  4. Review the filters. Leave Export only unsaved contacts off if you want both saved and unsaved contacts that are available. Keep Include admins in group export on to include administrators. When selecting multiple groups, enable Dedupe by phone if you want repeat phone numbers removed across sources.
  5. Run Refresh Preview. Check the row count, worksheet count, skipped entries and warnings. Change your selection or filters if the preview is not what you expected.
  6. Choose Export Contacts. Wait for the workbook download to finish. Open the file in Excel or another application that supports XLSX.

Check the workbook before using it

Review the Summary worksheet and the contact worksheets. Check names, phone values, source group and admin information where available. A preview count is a count of export rows, not a guarantee that every row contains a usable phone number.

If you exported several groups, decide whether you need group membership preserved or a deduplicated contact list. The same person may legitimately belong to more than one group. Removing duplicates can change the number of rows, so choose that setting to match your purpose.

For CRM import, map the columns to your CRM's fields and treat phone values as text. The extension downloads XLSX directly. If your CRM requires CSV, save the relevant contact worksheet as CSV in your spreadsheet application, then check that leading plus signs and zeros are preserved. Keep the original workbook as your reference.

When the result is incomplete

The group does not appear

Check that you are signed in to the correct WhatsApp account and can access the group in WhatsApp Web. Open the group, wait for it to load, then choose Refresh Context. If needed, reload WhatsApp Web and reopen the extension.

The preview has no rows

Confirm that Groups mode is selected and a group is checked. Turn off the unsaved-only filter for an initial test, then refresh the preview. If the group information is still loading, wait and try Refresh Context again.

Some phone numbers are missing or unfamiliar

WhatsApp may expose an internal contact identifier instead of a phone number, or may not expose a number at all. Do not assume every numeric value is a callable phone number. Check the resolution information and compare with details visible in WhatsApp before importing or using the data.

The export takes longer than expected

Keep the tab open and wait for a result or error. Test one group first rather than selecting every group. If an error repeats, send support the extension version, browser version and exact error text; omit private contact lists.

Contacts, not a conversation backup

This guide covers group contact records. A contact workbook is not an archive of every message or attachment in a conversation. The export process described here does not send messages to group members.

Files are generated locally and downloaded to your device. Share the workbook only with people who should have access to the contact information. See the privacy policy for the product's data-handling details.
